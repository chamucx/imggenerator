# 🖼️ Azure AI Image Generator

Generador de imágenes a partir de descripciones de texto usando **Azure AI** y Python.  
Este proyecto demuestra cómo conectar con el servicio de generación de imágenes de Azure, enviar prompts personalizados y recibir imágenes listas para descargar y utilizar.

## 🚀 Características
- Integración con **Azure AI Image Generation API**.
- Entrada de texto (*prompt*) en español o inglés.
- Generación de imágenes en diferentes tamaños.
- Ejemplos de prompts listos para usar.
- Código listo para ejecutar localmente o desplegar en la nube.

## 📋 Requisitos
- Cuenta en [Microsoft Azure](https://azure.microsoft.com/free/).
- Un recurso de **Azure AI / OpenAI Service** habilitado para generación de imágenes.
- Python 3.9 o superior.
- Claves de API y endpoint del servicio (desde el portal de Azure).
